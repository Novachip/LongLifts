# LongLifts

A simple 5x5 dumbbell workout tracker based on the StrongLifts method.

## Features

- **Two alternating workouts (A/B)**
  - Workout A: Goblet Squat, Dumbbell Bench Press, Dumbbell Row
  - Workout B: Goblet Squat, Dumbbell Overhead Press, Dumbbell Romanian Deadlift
- **5 sets of 5 reps** per exercise
- **Progressive overload** - weight auto-increases when you complete all sets
- **Rest timer** with audio alert (adjustable 15s - 5min)
- **Workout history** tracking
- **Stats** - total workouts, streak counter, current weights
- **Works offline** (PWA)
- **Installable** on mobile devices

## How to Use

1. Select Workout A or B
2. Tap sets to mark as completed (green) or failed (red)
3. Rest timer starts automatically after each completed set
4. Tap "Complete Workout" when finished
5. Weights increase by 1kg for exercises where you hit all 5x5

## Install on Mobile

- **Android**: Open in Chrome > Menu > "Install app"
- **iOS**: Open in Safari > Share > "Add to Home Screen"

## Data Storage

All data is stored locally in your browser (localStorage). Data does not sync between devices.
